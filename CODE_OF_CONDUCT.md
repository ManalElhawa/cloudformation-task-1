# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and inclusive environment for everyone who participates in this project.

We expect all contributors to communicate professionally and respectfully, regardless of background, experience level, or role.

## Expected Behavior

Examples of behavior that contribute to a positive environment include:

- Being respectful and considerate of others.
- Giving constructive feedback.
- Accepting differing opinions and perspectives.
- Focusing on the technical issue rather than the individual.
- Taking responsibility for mistakes and learning from them.
- Respecting project maintainers and community members.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Trolling or deliberately disruptive behavior.
- Publishing or sharing someone's private information without permission.
- Threats or intimidation.
- Any other conduct that would reasonably be considered inappropriate in a professional environment.

## Reporting Issues

If you experience or witness unacceptable behavior, please report it privately to the project maintainers.

Please do not report sensitive issues through public GitHub issues or pull requests.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

They may take any action they consider appropriate in response to unacceptable behavior, including removing content, closing issues or pull requests, or restricting participation in the project.

## Scope

This Code of Conduct applies to all project spaces and interactions associated with this repository, including issues, pull requests, discussions, and other project-related communications.

## Attribution

This Code of Conduct is based on principles from the Contributor Covenant and has been adapted for this project.
